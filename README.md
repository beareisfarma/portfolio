# bea.tech — Portfólio de Beatriz Reis

Landing page profissional para divulgação de serviços digitais.

**No ar:** https://beatriz-reis.vercel.app

Este repositório é só o portfólio, de propósito. Ele morava numa pasta do
repositório `Projetos`, junto com os apps; portfólio é feito para ser visto e
não pode depender da visibilidade de um repositório de trabalho.

## Projetos exibidos
- **Rep.Rota** — Sistema de gestão de rotas para representantes e consultores
- **Finances Control** — Dashboard de organização financeira
- **Bot Assistente** — Secretaria virtual 24h no WhatsApp
- **Projeto Pharma** — Ferramenta clínica confidencial (NDA)

## Como publicar

Projeto Vercel `beatriz-reis`, ligado a este repositório: **todo push na `main`
publica sozinho**. Não precisa rodar nada na mão.

## Como atualizar

O site inteiro é o `index.html` (HTML + CSS + JS num arquivo só) mais as
imagens em `img/`. Editar e dar push.
